# M1-01 子任务「安全与验收」

## 目标与范围

在 `feature/m1-01-acceptance` 建立外部 `IncidentScenario -> IncidentOutcome`
薄组合层，组合调查 loop 的只读执行结果、DurableStore/worker 的业务状态与
人工控制结果；不重写工具执行器、调查 loop、持久化或恢复模块。验收入口只暴露
证据 ID、决定、动作、权限、人工交互、handoff 原因和最终状态。
