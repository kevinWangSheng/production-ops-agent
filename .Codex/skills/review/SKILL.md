# Review

1. Inspect recent scoped changes and the relevant PRD/SPEC decisions.
2. Review Standards: project instructions, module depth, locality, testability, operability, and evidence quality.
3. Review Spec: external behavior, immutable acceptance steps, out-of-scope exclusions, and safety boundaries.
4. Check whether model authority, credentials, execution, or verification crossed an unapproved seam.
5. Report findings by severity, exact evidence, and remaining unverified areas.
