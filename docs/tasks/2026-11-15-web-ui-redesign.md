## 目标与范围

给工作台全部页面重新做一遍视觉设计，只出静态设计稿，本阶段不改模板、样式和后端。页面共 11 个模板文件（`opspilot/web/templates/`）：事故列表、事故详情、转人工事故、告警片段、证据、复盘审核、知识、版本变更列表与详情、暂停控制，加公共骨架。

## 已裁决（用户，2026-11-14 与 2026-11-15）

- 视觉方向用事故页设计稿第二版；不装官方 `frontend-design` skill，不用画布工具，不引入 Tailwind 或组件库。
- 做法：页面任务说明 + 点名禁止项 + 截图自检 + 另一个模型评审。
- 读者：没见过产品的资深工程师，五分钟看懂一次事故。
- 范围：全部页面重做设计；先不实现。
- 设计稿数据与真实 Run 逐项核对，不编数据。

## 前提与完成条件

- 前提：工具面拓展本机部分已合并；本任务在本机进行，不依赖租机评测。
- 完成条件：设计说明合并；每个页面有一张静态稿，覆盖正常态、空态和该页特有的降级态，数据来自同一次真实 Run，现有页面的操作项都有位置；每张稿经另一个模型按设计说明评审；用户看过主路径三页（事故详情、事故列表、复盘审核）。
