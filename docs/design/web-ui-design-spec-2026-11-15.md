# 网页工作台设计说明（2026-11-15）

状态：设计阶段，未实现。对应 GitHub issue「网页 UI 重做」（#572）。

本文规定工作台全部页面共用的视觉取值和规则。取值提炼自用户 2026-11-14 选定的事故页设计稿第二版（保存在仓库外，文件名 `opspilot-ui-incident-2026-11-14-c2.html`）；与设计稿不一致时以本文为准。

## 读者与页面任务

读者是没见过产品的资深工程师，要在五分钟内看懂一次事故：出了什么事、Agent 的结论是什么、结论靠哪些证据、恢复了没有、人做过什么。

每个页面先写清楚一句「这页帮读者完成什么」，再决定放什么内容。回答不了这句话的内容不放首屏。

## 取值

### 颜色

一套中性色，一个强调色，一个错误数据色。不再增加色相。

| 名称 | 值 | 用途 |
|---|---|---|
| `--bg` | `#fbfbfa` | 页面底色 |
| 白 | `#fff` | 顶栏、按钮、输入框、抽屉 |
| `--ink` | `#1d1e21` | 正文、标题、主按钮底色 |
| `--ink2` | `#4d5057` | 次要正文、说明 |
| `--ink3` | `#7d8088` | 标签、时间、来源说明 |
| `--ink4` | `#a9abb1` | 分隔符号、坐标轴、空心标记边 |
| `--line` | `#e7e5e0` | 常规分隔线 |
| `--line2` | `#d6d4ce` | 较重的分隔线、控件边框 |
| `--tint` | `#f3f2ef` | 药丸底色、原始文本底色、量条底 |
| `--acc` | `#0d6b61` | 链接、引用编号、正常/已恢复数据 |
| `--acc-soft` | `#e4f0ed` | 跳转定位后的短暂高亮 |
| `--err` | `#b23a30` | 仅用于错误数据：图表错误序列、失败的查询 |
| 斜纹 | 135° 斜线，`#cfcdc6` 1.5px，间隔 5px | 缺失数据 |

红色不用于标题、边框、按钮或状态标签。图表里非错误序列用 `#5c6068`，恢复条的降级段用 `#d79a94`。

### 字体与字号

- 正文字体：`"IBM Plex Sans"`，后备 `-apple-system, BlinkMacSystemFont, "Segoe UI", Helvetica, Arial, sans-serif`。
- 等宽字体：`"IBM Plex Mono"`，后备 `ui-monospace, SFMono-Regular, Menlo, monospace`。用于标识符、查询原文、时间戳、哈希、引用编号。
- 字重只用 400、500、600。
- 基准 `14px/1.55`。

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 页面标题 | 24px（窄屏 21px） | 600 | 每页一个 |
| 结论句 | 20px / 行高 1.5（窄屏 18px） | 400 | 全页最大的正文，最宽 70 个字符 |
| 侧栏主值 | 18px | 500 | 恢复判定等 |
| 区块标题 | 17px | 600 | 主栏区块 |
| 摘要带答案 | 15.5px | 500 | |
| 侧栏区块标题 | 15px | 600 | |
| 组标题 | 14.5px | 600 | |
| 正文 | 14px | 400 | |
| 说明、表格、来源 | 12.5–13px | 400 | |
| 等宽小字 | 11.5–12px | 400/500 | 引用编号、时间轴刻度 |

不使用全大写小标签，不加字间距做装饰。

### 间距与版式

- 页面最宽 1440px，左右留白 32px（窄屏 16px），上 24px，下 56px。
- 顶栏高 52px，白底，下方一条 `--line`。
- 详情页两栏：主栏自适应，侧栏 352px，栏距 64px；侧栏随整页滚动，不吸顶、不做内部滚动（侧栏内容常高于一屏，内部滚动会藏住入口）。1180px 以下合为一栏。
- 区块之间：上方一条 `--line`，线上 32px、线下 28px。首个区块无线。
- 行内条目之间：一条 `--line` 加 7–12px 上下留白。
- 圆角：量条和色块 2px，按钮和输入框 5px，药丸全圆。
- 阴影只用于右侧证据抽屉。
- 断点：1180px（两栏变一栏）、720px（窄屏）。

### 部件

| 部件 | 规则 |
|---|---|
| 来源记号 | 8px 小图形加文字：空心菱形 = 告警源，圆点 = Agent，方块 = 代码检查，三角 = 人。靠形状和文字区分，不靠颜色 |
| 引用编号 | 等宽 11.5px、强调色、虚线下划线，点击跳到对应证据 |
| 药丸 | 11.5px、`--tint` 底、`--line2` 边。只给真正需要标记的状态 |
| 按钮 | 白底 `--line2` 边；每组最多一个主按钮（`--ink` 底白字）；禁用时半透明 |
| 表格 | 12.5px，只有行下边线，表头 500 字重 `--ink3` |
| 键值表 | 左列标签 `--ink3`，右列等宽 |
| 折叠 | `details`，文字开关「Show / Hide」或「+ / −」，强调色 |
| 量条 | 高 8px，分段：强调色 = 有数据，`--ink4` = 无数据，错误色 = 失败，斜纹 = 未查询 |
| 原始文本 | 等宽 12.5px、`--tint` 底、圆角 4px、保留换行。来源返回的不可信文本必须放在这种框里并标明来源 |

## 规则

1. 不用彩色顶边、彩色侧条。
2. 分组靠间距和细线。不给每块加边框，不在框里再套框。
3. 每个状态只有一个权威位置，给出判定、依据和来源。摘要带可以用一句话复述并链接到它；时间线只记事件发生的时刻，不复述状态的依据。同一状态在不同位置的措辞逐字一致。
4. 首屏（1440×900）药丸不超过四个。
5. 结论句是全页最大的正文；告警名是标题下的安静副标题。
6. 时间线是第三层信息：无外框、无角色标签，只有记号、时间、一句事件。
7. 每条陈述都能看出是谁说的（告警源、Agent、代码检查、人）。
8. 调查报告与恢复判定是两个独立结论，分开摆放、分别标明来源。报告不证明恢复。
9. 不编数据。没有的值用斜纹或「无数据」文字标明缺失，不留白、不估值。
10. 产品是只读的：页面只出现后端当前状态允许的操作，不画产品没有的写操作。
11. 颜色不单独承载含义，同时有文字或形状。键盘焦点有 2px 强调色外框。
12. 三个宽度都要成立：1440、1180 以下、720 以下。宽表格和图表在自己的容器里横向滚动，页面本身不横向滚动。

## 出稿与评审

- 每张静态稿用同一次真实 Run 的数据，数据逐项对得上记录。
- 每页至少覆盖：正常态、空态，以及该页特有的降级态（调查进行中、等待人工、无结论、调查不完整、数据已按保留期清理等）。
- 状态怎么画：有真实记录的状态用真实记录画。没有真实记录、但会改变页面骨架的状态画成示意态，值全部用缺失表示法留空，示例行就地标明「example row」，不放看起来像真实值的占位值。只多一行或一个标记的状态不单独画，在稿子的设计备注里写明它出现的位置和触发条件。
- 出稿后自己截图检查三个宽度，再交未参与出稿的全新上下文评审者，评审对照本文规则、页面任务、产品约束和现有模板；数据另由独立核对者逐项对原始记录。出稿者和协调者的自检不算评审。

## 待定

- 字体加载方式。设计稿从 Google Fonts 加载 IBM Plex；现有产品页面只用系统字体、不请求任何外部资源。实现时在「随镜像自带字体文件」和「只用后备系统字体」之间选一个，不从外部地址加载。
- 深色主题。设计稿顶栏有主题切换占位，本文只定义浅色取值。
- 界面语言。现有页面除版本变更详情页的固定提示外都是英文。
