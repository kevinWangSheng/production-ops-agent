## 目标与范围

Jaeger 2.21 起删掉了 v1 搜索接口，ITBench 钉的 2.23 只答 `/api/v3/*`，`otel-demo-ext` 的五个 trace 工具因此全部失败或误报（S20 的 `SOURCE_ERROR/INVALID_PARAMS`）。本任务只让 `otel-demo-ext` 在 v3-only 的 Jaeger 上可用；`otel-demo` profile 与 v1 输出字节不变；不改提示词、调查 loop、注册的错误类和参数 schema。

## 前提与完成条件

- 前提：用户常设授权覆盖本地真实软件环境调用；无需用户裁决（预审结论）。
- 完成条件：独立合同测试与安全测试通过；钉值更新后 CI 通过；本地 Jaeger 2.23 经产品执行器实测；独立审查无阻塞项。

## 合同（r1，按预审推荐采纳；实施中一项用户裁决 U1）

| 编号 | 采纳 | 理由 |
|---|---|---|
| D1 | 每个 worker 进程、每个 `traces_endpoint` 首次调用探测一次并缓存：`/api/services` 200 且体是 v1 envelope → v1；404（或 200 非 envelope）→ 查 `/api/v3/services`，200 且 `{"services":list}` → v3；否则不缓存、走 v1 路径返回原始错误 | 按 id 的 404 有歧义，不能每次回退；实测 base 写错时会返回 200 HTML，所以加 envelope 判断（实施补充，见下） |
| D2 | 只改 `otel-demo-ext`，`otel_demo.py` 一字不改 | ITBench/Holmes 跑 ext，冻结模块不动 |
| D3 | ext 里 `traces_search` 路由到包装 transport：v1 原样委托，v3 用同一 `_get` 发 v3 请求，归一后调 `project_traces`；`SERVICES` 检查保留 | v1 字节不变 |
| D4 | 凭据行为不变：`traces_search` 带 bearer，A4 工具匿名 | 不扩权 |
| D5 | OTLP 归一成 v1 形状（hex id、resource 服务与版本、µs 时间、ERROR 合成两个 tag、message→`otel.status_description`、事件→logs、parent→CHILD_OF、按 traceId 分组） | 复用投影，record 形状不变 |
| D6 | 不新增模型可见字段，status.message 与 exception 事件走 `_clipped` 脱敏 | 脱敏规则不变；M67 变异覆盖 |
| D7 | 参数映射：RFC3339 时间、`query.serviceName/operationName/attributes/durationMin/durationMax/searchDepth`；超过 limit 的按最新优先裁掉 | 现有参数都能表达 |
| D8 | 搜索 404 = 空结果（no_data）；按 id 404 走现有 not-found；400 取 `error.message`；5xx 不变；501 按执行器默认 | 消除 S20 误报，不改 `error_classes` |
| D9 | 描述不动；v3 模式把 `_RING_NOTE`/`_LIST_NOTE` 换成如实的 v3 note，record `query` 加 `"jaeger_api":"v3"` | 不改 tool_schema_revision |
| D10 | `PROJECTION_REVISION` 升到 `m1-01-tool-view-v20` | C3 要求投影变就升 |
| D11 | 测试由独立作者编写（362da93f），本分支不改其断言 | AGENTS.md 独立测试规则 |

实施中补充（可逆，Agent 自定）：D1 的「200 就是 v1」收紧为「200 且是 v1 envelope」，依据是本地 2.23 对未知非 API 路径返回 200 HTML（证据见下）。RFC3339 按 Go RFC3339Nano 写法输出（去掉尾零）。

用户裁决 U1（2026-11-25，选推荐）：D1 探测让两条恶意输入范围检查（`tests/acceptance/test_566_runbook_fetch_postgres.py`、`tests/safety/test_safety_model_inputs_postgres.py`）多看到一次读。断言改为：至多一次 `GET {JAEGER_URL}/api/services`（URL 完全相等、无查询参数），其余数据读仍恰好一次且原有检查全部保留。改动由独立测试作者完成（`4a0024d8`，cherry-pick 进本分支）。
