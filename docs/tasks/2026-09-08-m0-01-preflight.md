## 目标与范围

回答“用哪个固定环境和配置，能否安全启动首条真实 DeepSeek + 白名单 trace 兼容实验”。本任务交付资源/配置/可执行入口及其离线自测；真实多轮协议、故障恢复、OTel 调查和正式评测另按 M0 合同运行。避免把前提缺失藏在泛化的环境就绪声明中。

## 已知前提

2026-09-08 主工作区 f225d82 上 make check 通过（5 项 doctor 测试）；doctor --lab 返回 2：Docker/Compose 客户端可用，daemon 不可达，kubectl/Helm 缺失。本机 16 GiB 内存、10 逻辑 CPU、约 44 GiB 可用磁盘。这些是上轮只读预检结果，执行时复核，不代表资源已分配。

无项目模型/trace 加载器、运行依赖锁或实验脚本；`.env.example` 只定义拟用配置。用户已在主工作区 `.env` 填写两个 key、权限 0600，未验证有效性；后续入口显式读取该路径，仍需明确 LangSmith 项目区域及必要 workspace，并记录首轮调用额度/期限；现有 CNY 1000 参考不算授权。容器安装/启停方案先限定资源与影响；本任务文件不自动授权干扰其他正在运行的项目。

## 执行步骤与判据

1. 读取 SPEC 当前门槛、C3 引用合同及资源规划，核查 Git/worktree。对现有入口运行以下只读/本地检查，逐条保留退出码，不能用最后一条成功覆盖前面的失败：

   ```sh
   pwd
   git status --short
   git worktree list
   make doctor
   python3 scripts/doctor.py --lab
   ```

   macOS 资源盘点执行 `sysctl -n hw.memsize hw.logicalcpu`、`vm_stat`、`df -h .`；容器 daemon 就绪后检查分配的 CPU/内存/磁盘，Linux 使用对应只读工具。doctor 基础应返回 0；lab 当前预期为 2，补齐后应为 0，但二者均不能代替实际数据源查询。机制实验不强制先准备完整 Kubernetes，缺项按受影响工作包记录。

2. 助手固定最低所需的 Python 客户端及 trace SDK 版本，在任务 worktree 的锁文件管理；选择任务专用 PostgreSQL/端口/卷和容器容量，核对已有实例归属。输出安装/启停命令、资源上限、存储位置、保留/清理安排；需要新增支出时给出具体额度和期限，未获授权不采购。

3. 实现本任务专用的配置校验与实验入口，新增文件名和命令在实现后写回本节；当前不要运行不存在的命令。配置按键解析且不执行；秘密不输出、不混入异常/trace。缺 key、区域、有效授权/预算、deadline 时在网络调用前失败；预算缺失/0 禁止付费调用。离线模式不得访问网络。白名单出口先用含虚假 key/provider 私有字段的 fixture 验证过滤；不能打开全量自动 tracing。

4. 为下一项真实实验冻结具体请求 fixture：合成目标 `m0-target-a`、只读假数据工具 `read_fixture`，返回固定时间窗和证据 ID；与真实业务及保留集无关。正常用例要求实际模型产生工具调用、配对结果续接并返回可解析结果；每次请求有期限和累计额度，是否调用工具按可观察结果判断，不依赖思维链。另列流中断、参数错误、工具错误、配对压缩、provider 字段续传的独立用例，预期成功/失败状态和重复规则在真实运行前固定。

5. 离线自测通过及独立审查完成后，核对用户私有配置是否齐全（只输出布尔状态）。实际连通性实验使用合成资料、既有数据用途和明确费用授权，第一条真实模型链路同时验证白名单 trace；不通过“打印完整请求/响应”调试。尚无调用授权或凭据时，记录前提缺失并交接，不将入口离线成功记为服务接通。

## 交付与证据

- 任务内记录 OS/架构、代码 SHA（dirty 时文件 hash）、Python/依赖锁、资源实测、模型/endpoint/thinking/effort、授权引用和秘密存在状态；不收集环境变量全文。
- 每个用例记录 fixture 版本、预期/实际、退出码、调用次数、已知/未知费用、脱敏证据路径和失败处置。临时原始记录放本任务专用 ignored 目录，审核后的无秘密摘要保存在任务记录；唯一必要证据须在 worktree 清理前保留。
- 完成条件是具体配置、版本、入口命令、离线拒绝/过滤自测和独立审查均可复现，真实调用的前提与下一实验合同齐全；没有真实运行记录时，模型/trace 连通性仍为未验证。生产权限、完整环境/恢复/评测及 M0 退出均另有验收。
- 失败先保留证据并分类为设施/凭据/预算/协议/设计；未授权的安装或资源影响不强行处理，不为了通过而删验收或隐藏缺测。
