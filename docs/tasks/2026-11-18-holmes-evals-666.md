## 目标

把 HolmesGPT 公开评测集里 B1 的 30 道 Elasticsearch 题变成 OpsPilot 能跑、能判分的评测：题面原文经网页人工提问交给 OpsPilot，报告按确定性规则转成文本，用上游 classifier 提示词二值判分，每题 3 遍。结果单独成轨，标「HolmesGPT 公开评测集（竞品自评集）」。全部是评测侧代码（`scripts/holmes_evals/`），`opspilot/` 一个字节不改，不翻任何 `passes`。

## 行为

- **答案隔离**：题目加载器只返回白名单字段（题面、tags、toolsets、before/after_test、setup_timeout、port_forwards、include_tool_calls、memories_generated、skip、enable_todo、evaluation、cluster_name）；`expected_output` 只有判分函数能读，judge 的理由文本只写 git 忽略的 `tmp/`，不打印、不入库。实现与测试一律用合成题目录，不读真实题的 `expected_output`。
- **钉版本**：启动时核对上游 checkout 的 HEAD 是 `a0009195468ebc55a7dff7d602b61feabe3cda1b`、`tests/llm/utils/classifiers.py` 的 sha256 与钉值一致，不符就拒绝。
- **报告转文本**：用 `opspilot.evaluation.binary_judge.project_opspilot_report`；题目 `include_tool_calls: true` 时照上游 `property_manager.py:212-231` 的格式逐字追加工具调用附件（每次调用的工具名、规范 JSON 参数、已脱敏存储视图的完整输出，含被拒调用，不截断）。没有可用报告时不送 judge、记 0、原因 `REPORT_REJECTED_BY_PRODUCT`。
- **反平移**（H-9）：评测给固定时间题的数据加了平移量时，送 judge 的文本里落在「平移后数据范围 ± 1 小时」内的 ISO 8601 时间与 `YYYY-MM-DD` 日期减去平移量还原；范围外的时间不动；只写时刻不写日期的说法不改（已知限制，披露）。返回改写个数。
- **判分**（H-16）：单一 judge Z.ai `glm-5.3-flashx`，复用 `binary_judge` 的 `ProviderConfig`/`HTTPCompletionClient`/`parse_completion`；提示词用上游 strict 与 loose 两段原文（按题的 `evaluation.correctness.type`，缺省 strict），`{{expected}}` 用 `"\n- ".join(期望条目)` 填，后接 `binary_judge.ANSWER_INSTRUCTION`；新常量 `HOLMES_EVAL_PROMPT_SHA256` 钉两段模板加作答说明。失败重试最多 2 次；请求超过 4 MiB 记 `JUDGE_REQUEST_OVERSIZE` 不重试。R8-13 的 5 题（275–278、280）不判建议条数、不附「# Suggested Skills」段、不跑 `rerun_with_memory`。
- **计分**（H-17、H-18）：主分 = 通过次数 /（题数 × 3）；每题 3 遍中过 1 或 2 遍为摇摆，补跑 3 遍单列、不进主分；无报告、judge 用尽、环境坏的 trial 记 0 留分母并单列；另报多集群 10 题一组、受时间框限制组、去掉「题或 harness 坏了」后的分数。

## PR-A 公开接口（测试作者按此写测试；改动须经 lead 同步）

模块在 `scripts/holmes_evals/`（包，带 `__init__.py`）：

- `questions.py`
  - `UPSTREAM_COMMIT: str`、`CLASSIFIERS_SHA256: str`
  - `B1_QUESTIONS: tuple[str, ...]`：30 个上游题目目录名（不含 183a/f/g、186、271、274、279）；`MULTI_CLUSTER: frozenset[str]`（259_wrong、260_global、261–267、269 的目录名，10 个）；`SKILL_ASSERTION_DROPPED: frozenset[str]`（275–278、280）
  - `verify_upstream(root: Path) -> None`：HEAD 或 classifiers 哈希不符时抛 `UpstreamMismatch`
  - `load_question(root: Path, qid: str) -> Question`：冻结 dataclass，只有白名单字段（属性名用上游键名）；`Question` 上不存在任何答案字段
  - `judge_mode(q: Question) -> Literal["strict", "loose"]`
- `text.py`
  - `ToolCall`（dataclass）：`tool: str`、`params: Mapping`、`output: Any | None`、`refused_code: str | None`、`refused_reason: str | None`
  - `format_tool_calls(calls: Sequence[ToolCall]) -> str`：上游附件格式
  - `Shift`（dataclass）：`seconds: int`、`shifted_min: datetime`、`shifted_max: datetime`
  - `deshift(text: str, shift: Shift | None) -> tuple[str, int]`
  - `report_to_text(report: ReportV2 | None, calls: Sequence[ToolCall] | None, shift: Shift | None) -> ConvertedText`：`ConvertedText` 有 `text: str | None`、`deshift_count: int`、`with_tool_calls: bool`、`reason: str | None`（无报告时 `REPORT_REJECTED_BY_PRODUCT`）
- `judge.py`
  - `UPSTREAM_LOOSE_PROMPT: str`、`HOLMES_EVAL_PROMPT_SHA256: str`
  - `judge_messages(expected: Sequence[str], output: str, mode) -> list[dict[str, str]]`
  - `judge_trial(client: CompletionClient, config: ProviderConfig, root: Path, qid: str, output: str, rationale_dir: Path) -> JudgeResult`：在函数内读该题 `expected_output`，只返回 `choice`、`passed`、`error_code`、`attempts`、`prompt_sha256`、`request_bytes`；理由写进 `rationale_dir`，不在返回值里
- `scoring.py`
  - `Trial`（dataclass）：`qid`、`index`（1..3 主遍，4..6 补跑）、`passed: bool`、`category: Literal["ok","no_report","judge_exhausted","env_broken"]`、`time_box_limited: bool`
  - `score(trials: Sequence[Trial], questions: Sequence[str]) -> dict`：`main`（passes、denominator、rate）、`per_question`、`swing_questions`、`rerun`、`multi_cluster`、`time_box_limited`、`excluding_env_broken`
