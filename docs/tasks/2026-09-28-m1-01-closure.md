## 结论

## 关键认识

- 早期每 Run 4 次请求等上限来自 M0 成本控制与 v4 冻结，未对照上游；它们让调查被强制结束、写报告时看不到工具定义，是多类错误的主因。对齐上游后错误逐包下降。
- 剩余错误以 e 类为主：模型在自由文本中写错数值区间、计数与来源；视图语义与代码汇总已消除 a/b/c/d 类，e 类在真实 Run 中未随 span_groups 下降，成因未做逐条归因。
- 报告修复重试（至多 1 次）能修格式与引用错误，不保证内容正确。
