What each status means

Needs a human: the black label says what to do

{{ ui.pill("Review postmortem", todo=true) }}
Closed; a postmortem version waits for approve, return or reject.
{{ ui.pill("Handle outside OpsPilot", todo=true) }}
The alert matched no single registered target, so no Run started. The incident page offers no actions for it.
{{ ui.pill("Resume", todo=true) }}
Paused by an Operator, or by a suspension. Releasing a suspension resumes nothing.
{{ ui.pill("Cancel or take over", todo=true) }}
The Run is blocked; only cancel moves it on.
{{ ui.pill("Register or close", todo=true) }}
Taken over: a human owns the incident. Registering a remediation starts a Recovery watch.
{{ ui.pill("Ask or take over", todo=true) }}
The Agent stopped and handed the Run to a human. Ask or add a correction to let it continue.
{{ ui.pill("Close or reopen", todo=true) }}
The Recovery watch confirmed recovery and nobody closed the incident yet. A marker shows when the alert fired again afterwards.
{{ ui.pill("New Run or close", todo=true) }}
Open after cancel, with no Run in progress.
{{ ui.pill("Close or register", todo=true) }}
The report is published and no Recovery watch is running.
