### 下一条真实实验的固定用例合同（尚未执行）

这是机制验证，不是 F1 的完整 IncidentScenario/Outcome 或正式 eval 冻结包。所有用例固定上面的 fixture v1、DeepSeek 官方 deepseek-v4-pro / thinking enabled / high、适配器与锁 hash。首次真实链路必须同时完成白名单 trace 上传和回读；trace 失败单独失败，不能把模型结果删掉。每例预定 3 次，失败/放弃都保留分母；参数错误不盲重试。若具体授权预算不足以覆盖这份合同，执行前缩小有界批次并记录，不能跑完成绩后挑样。

1. **normal**：真实模型必须产生 read_fixture 工具调用；校验目标/参数、记录配对结果，再续接得到可解析 target/evidence_id，缺工具调用或证据不匹配即失败。预期 completed。离线已验证固定替身 wire，真实能力未验证。
2. **stream-interrupted**：代理在收到工具参数片段、完整 finish 前断流；不得执行工具，保存不完整/未知费用占用并有界失败或交接。预期 incomplete/handoff，真实及替身流式路径尚未实现。
3. **invalid-arguments**：受控替换工具参数为 malformed JSON 或其他 target；请求被确定性拒绝，不查询其他目标；错误记录配对后按合同续接。当前离线验证拒绝，错误响应后的真实续接待做。
4. **tool-error**：同一 read_fixture 返回固定 unavailable 错误；保留 tool_call_id 与失败分类；模型不得把错误当作成功证据。预期 inconclusive/handoff，真实路径待做。
5. **paired-compression**：仅保留完整 assistant/tool 组后续接；缺结果或重复配对在模型请求前拒绝；保留原证据时间/ID。当前只验证完整组及拒绝，压缩算法和真实链路未验证。
6. **private-continuation**：同 provider/同 Run 完整续传必要 reasoning_content；换 provider/Run 或缺字段时 INCOMPATIBLE_STATE，不猜测删除；出口植入虚假 key/私有字段，LangSmith 接收体及回读均不得包含它们。当前验证合成同 Run wire 和本地 DTO；持久保存、重建、真实回读待做。

每次真实执行记录用例/重复序号、预期/实际、请求数/重试数、退出码、已知与未知费用、耗时、授权引用、deadline、版本/hash 和脱敏工件。上面的固定 Run UUID 仅用于永不上传的离线排演，live 必须生成独立稳定身份且不能复用它。
