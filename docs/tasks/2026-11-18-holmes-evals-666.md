## 目标

把 HolmesGPT 公开评测集里 B1 的 30 道 Elasticsearch 题变成 OpsPilot 能跑、能判分的评测：题面原文经网页人工提问交给 OpsPilot，报告按确定性规则转成文本，用上游 classifier 提示词二值判分，每题 3 遍。结果单独成轨，标「HolmesGPT 公开评测集（竞品自评集）」。全部是评测侧代码（`scripts/holmes_evals/`），`opspilot/` 一个字节不改，不翻任何 `passes`。

## 行为

- **答案隔离**：题目加载器只返回白名单字段（题面、tags、toolsets、before/after_test、setup_timeout、port_forwards、include_tool_calls、memories_generated、skip、enable_todo、evaluation、cluster_name）；`expected_output` 只有判分函数能读，judge 的理由文本只写 git 忽略的 `tmp/`，不打印、不入库。实现与测试一律用合成题目录，不读真实题的 `expected_output`。
- **钉版本**：启动时核对上游 checkout 的 HEAD 是 `a0009195468ebc55a7dff7d602b61feabe3cda1b`、`tests/llm/utils/classifiers.py` 的 sha256 与钉值一致，不符就拒绝。
- **报告转文本**：用 `opspilot.evaluation.binary_judge.project_opspilot_report`；题目 `include_tool_calls: true` 时照上游 `property_manager.py:212-231` 的格式逐字追加工具调用附件（每次调用的工具名、规范 JSON 参数、已脱敏存储视图的完整输出，含被拒调用，不截断）。没有可用报告时不送 judge、记 0、原因 `REPORT_REJECTED_BY_PRODUCT`。
- **反平移**（H-9）：评测给固定时间题的数据加了平移量时，送 judge 的文本里落在「平移后数据范围 ± 1 小时」内的 ISO 8601 时间与 `YYYY-MM-DD` 日期减去平移量还原；范围外的时间不动；只写时刻不写日期的说法不改（已知限制，披露）。返回改写个数。
- **判分**（H-16）：单一 judge Z.ai `glm-5.3-flashx`，复用 `binary_judge` 的 `ProviderConfig`/`HTTPCompletionClient`/`parse_completion`；提示词用上游 strict 与 loose 两段原文（按题的 `evaluation.correctness.type`，缺省 strict），`{{expected}}` 用 `"\n- ".join(期望条目)` 填，后接 `binary_judge.ANSWER_INSTRUCTION`；新常量 `HOLMES_EVAL_PROMPT_SHA256` 钉两段模板加作答说明。失败重试最多 2 次；请求超过 4 MiB 记 `JUDGE_REQUEST_OVERSIZE` 不重试。R8-13 的 5 题（275–278、280）不判建议条数、不附「# Suggested Skills」段、不跑 `rerun_with_memory`。
- **计分**（H-17、H-18）：主分 = 通过次数 /（题数 × 3）；每题 3 遍中过 1 或 2 遍为摇摆，补跑 3 遍单列、不进主分；无报告、judge 用尽、环境坏的 trial 记 0 留分母并单列；另报多集群 10 题一组、受时间框限制组、去掉「题或 harness 坏了」后的分数。

**可逆自定（一行理由）**
- 管理员身份取容器环境变量、口令走 stdin：驱动不读清单里的口令，进程参数里也看不到；用的是题目自己的管理员，与 R8-7「评测脚本用工程师凭据建只读账号」一致。
- ClickHouse 用 `users.d` 配置文件建账号：题里的 `default` 没有 SQL 访问管理，改清单属改题（R8-1 不改题）。
- 预检用产品自己的自查函数：与产品第一道判定同一份代码，授权脚本与白名单漂移时在投递前就以确定性错误报出，不浪费一遍模型调用。
- 账号不撤销：每遍题库随命名空间删除，账号一起消失；撤销会多一次 `kubectl exec`，失败了还会误报残留。

**已知限制（披露，不改）**：7 题的 `before_test` 都用 kubectl 与 kind 集群，本机跑不了，本机只用替身端到端，真实后端交租机冒烟（#669：每方言 1 遍后再全量，R8-27）；SQL Server 镜像只有 amd64、要 2–3 GB 内存，租机选 amd64；ClickHouse `users.d` 自动重载与 MySQL 8 镜像自带证书在集群内的行为【推断，租机冒烟核实】。

**现有合同测试**：按「默认值不变」设计，预计现有断言无须修改；若有测试钉了 `ALL_QUESTIONS` 或 `QUESTION_GROUPS` 的长度或键集合、`backend_of` 的取值集合、`ShiftRecord.reason` 的取值集合、summary `holmes_eval` 的键集合，会变红，列给 lead，不改断言。新增行为（题单与组、规格表、env 与隔离新条件、授权脚本与口令不进参数、预检与码、流程顺序与重试、summary 新字段与披露、runner 接受 c6 与 merge）需独立作者另写合同测试。
