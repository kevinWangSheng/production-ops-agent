## 实现中的可逆决定（Agent 自定，一行理由）

- 端口覆盖做成 `OPSPILOT_LAB_HOST_PORTS=key=port,…`，只在设了主机地址时生效：#462 退路只缺端口，键沿用 `COLIMA_ENDPOINTS`，不改 colima 与 kind 网络两条默认路径。
- 故障 key 用独立账号 `soakfault`，经 sudoers 以 lab 用户身份只跑 `fault.sh ""`：lab 的 kubeconfig 属 lab 用户，隧道账号保持只能转发。
- 噪声开关不扩 `kind_lab.FAULT_FLAGS`（它是 eval v1 白名单），soak 自带 `lab_fault.SOAK_FLAGS`，开关两方向幂等，重试不会因上次已成功而失败。
- A1 kill 后 30s 无条件 `compose up -d --no-deps worker`：`docker kill` 后重启策略是否生效未确认，补一次是幂等的。A1、A2 的条件（有 running Run / 空闲）最多等 30min，过时照跑并记 `condition_met=false`。
- 恢复类步骤（关开关、恢复出口、起隧道、拉起 worker）永不跳过；注入类步骤因 runner 停机迟到 >30min 记 `skipped: missed`，照实计入「未执行」。
- 读 PG 走 `compose exec postgres psql`（只读会话），因 PG 不发布主机端口；`queued` 时长用 runner 每 60s 的状态快照，因 runs 表没有状态时间列。
- 告警归属（按验收合同）：本次 episode 开启到下一次执行的 episode 开启（或 soak 结束）之间，`starts_at` 最早的 `CheckoutPlaceOrderErrorRatioHigh` 告警；再取同一 fingerprint、`received_at` 不早于 firing −2s 且在该窗口内的最早投递，作为它的归宿；token 只计已提交步骤的 `usage`（下界）。
- 隧道镜像 `alpine:3.21.3` + 发行版 autossh，按 tag 固定、未钉 digest（da-server 上构建时记录 digest）。

- 汇总器以独立验收测试 `tests/acceptance/test_soak_summarize.py`（45 例，独立作者按合同写）的模块 docstring 为原始目录与 `summary.json` 的合同；runner 直接写这个目录，`finish` 把 PG 导出转成它的格式（映射见 `scripts/soak/README.md`）。
- T0 冻结进计划文件（验收合同的 `planned_start` 是绝对时间）：runner 等到 T0 才写 `soak_start`，晚于 T0 5 min 拒绝启动，T0 之后重启接着跑。
- 计划只有一个输入单价：用 DeepSeek cache-miss 输入价（偏保守），出处写进计划。
- `alerts.jsonl` 来自 lab Alertmanager API，经故障 key 的只读 `alerts` 命令（API server service proxy），不另开端口。
- 隧道断开（A4 计划窗口之外）自动记为环境中断（S-R4），同时单记 `tunnel_down/up`。
- P8 发现（handoff `daserver-soak-prep-2026-11-04.md`）：`-R` 目标是 Compose 服务名（已如此）；install 后用 soak 文件组 `up -d --force-recreate` 重建全部服务（含 postgres），日志轮转用 `compose.soak.yaml` 即可；租机 Alertmanager 用 da-server 的 `alertmanager_token`、lab 账号凭据都走主机到主机 ssh 管道（README 步骤 1–3）。

- #477 第 1 轮（lead 定）：B2 关开关等恢复类步骤失败后每 60 s 重试直到成功，期间新的开关注入暂停（超 30 min 记 `injection_skipped`，原因写明前一个注入仍开着）；汇总 `stuck_work.injections_left_on` 与 step4 `injection_left_on:<id>` 列出有 on 无 ok off 的注入（只对计划带恢复步骤的注入，验收断言不变）。M1 Prometheus/隧道查询失败时三个角色都写 `up=0`，`prom_up.csv` 多一列 `source=query_failed`。M2 A4 计划断开窗口以停止时刻为准（有起隧道记录用它，否则停止 +10 min），再加 120 s 宽限；过了仍断就补记环境中断。L1/L2 租机公钥文件必须恰好一行；`soaktunnel` 的 sshd Match 段加 `AllowStreamLocalForwarding no` 和与 authorized_keys 一致的 `PermitOpen`/`PermitListen`。
