## 验收标准（防 slop）

验收者拿到本节标准与原始产物（视频文件、抽帧、字幕文本、博客草稿、所引证据路径），不拿作者结论。任一条不过即退回。

- 文字：每个数字能对到仓库冻结证据；失败与限制写出来；不用空洞形容词；一段一事；读者不需要懂项目内部术语。
- 视频：ffmpeg 定间隔抽帧加每次字幕切换帧逐帧看；字幕停留够人读完；无空镜；1080p 下字号可读；画面无密钥、token、内部地址；快进处标真实时长。
- 理解测试：先让另一个全新 Agent 只看成品复述「系统做了什么、效果如何」，与事实不符即说明表达不清。
