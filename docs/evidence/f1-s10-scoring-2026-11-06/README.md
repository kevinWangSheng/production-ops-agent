`summary.json` 是冻结摘要：两家 judge 的判词、确定性列、用户对每处分歧的裁决、出报告耗时、作废尝试、开考后修正、费用和输入文件的 sha256。原始 ledger、报告正文、judge 理由、题面、参数与答案均不入库；不含主机地址与凭据。

## 判法

- 先跑确定性检查（Q11）：不通过即一票否决，不送 judge。OpsPilot 另有「根因证据引用率」列，只作参考，不进对比分母（U3）。
- 其余尝试送两家异厂商二值 judge（`glm-5.3-flashx`、`gpt-5.6-luna`），提示词取上游 HolmesGPT `a0009195` 的 strict 分类器；两家对 OpsPilot 和 HolmesGPT 用同一提示词、同一输入投影。judge 未校准。
- 两家意见不一时由用户裁决。正式判分共 9 处分歧，全部是 GLM 判通过、OpenAI 判不通过；用户裁决 v2：7 处不通过，2 处通过。裁决标准与一致性复查见 `summary.json` 的 `disagreements`。

| 数据集 | 范围 | OpsPilot | HolmesGPT |
|---|---|---|---|

| | 配对对比（12 题） | 32/36 = 88.9%，pass^3 8/12 | 25/36 = 69.4%，pass^3 8/12 |
