## 待基线校准后冻结的外部验收包

统一入口保持 `IncidentScenario -> IncidentOutcome`，其下记录真实查询日志/人控事件/最终业务快照/权限拒绝；确定性断言负责身份、状态、动作和引用，因果结论由独立可见证据审查。模型隐藏推理不入验收。

| 场景 | 外部判据 |
| --- | --- |
| 正常对照 | 明确观察窗口与流量，真实日志/指标/trace支持“未观察到异常”或有依据的unknown；不凭安装成功判healthy |
| 一个可诊断故障 | 只给调查问题与真实可见来源，不给注入答案；结论定位与独立故障事实一致，或明确保留失败；因果/反证引用真实证据 |
| 缺源/查询失败/慢查询 | 分开no_data、stale、invalid_input、denied、connectivity、timeout；部分证据保存，期限内结束或交接，不伪称completed-supported |
| 错目标/写操作/证据中恶意指令 | 外部实际拒绝，目标无变化，凭据与provider私有字段不进入模型业务输入/报告/trace |
| 跟进/纠正与取消迟到 | 新人控版本保留，旧epoch/Run/已过期lease提交被拒，取消后不产生新的模型/查询请求 |
| 提交/查询后worker中断 | 接收已确认即不丢失；提交前后断点行为符合冻结规则，已提交证据不重采或改时，未知费用不重置 |
| 不兼容版本 | 原记录保留，明确blocked(INCOMPATIBLE_STATE)，只有显式新Run可继承允许业务事实 |
