|---|---|---|---|---|

| D21 | 给模型哪些数据（P6） | 只给水位以内的结构化投影、已采纳证据视图、人工动作文本、恢复结束投影与退回理由；原始证据按白名单字段脱敏；独立的字节与条数上限，超限不生成并记原因 | 投影与截断规则要测试 | 凭据注入、超限、未采纳证据、prompt injection 测试 |
| D22 | 失败怎么处理（P8、P10） | 引用校验失败：一次生成内最多一次结构/引用修正，仍失败存为 draft（结论 uncertain、机器可见失败原因），不进审核、不自动无限重试；供应商失败：不建版本，记一次生成尝试（错误类别 MODEL_REJECTED/MODEL_UNAVAILABLE），有上限退避重试。调用次数：一次生成尝试最多两次模型调用（生成 + 至多一次修正），供应商失败后的重试是新的生成尝试，两者都计入 D23 的生成预算 | 多一个生成尝试记录 | 「未生成 / 生成失败 / 引用失败」三态可区分 |
| D23 | 预算归属（P9） | 每次生成独立有界预算，不占调查 Run 的模型请求计数；单次调用沿用现有超时、请求大小与一个防循环上限；费用按余额差记账 | 多一个生成预算记录 | 预算耗尽、超时、重启测试 |
