## 决定与理由（执行者一行理由）

- 描述改写只拆句不改语义：保留原描述的全部约束（累计计数器、最大回看 = 窗口长度、`lookback_*` 与 `source_start_at` 语义、offset/@/超长选择器拒绝、24 KiB 截断、未返回即未知）；`tool_schema_revision` 随内容哈希变化。
- `delivered_from_context` fail-closed 的产品后果：`continuation_context`（交接后继任 Run 的 `view_bindings` 唯一产品来源）必须显式写出 `citable_as_fact`，否则继任 Run 永远无法把继承证据作为事实引用；已随本提交加上，值取自上一 Run 交付视图的标志。现有 loop 测试里手写的 ok 绑定按新合同补上 `citable_as_fact: true`（只改夹具数据，不改断言）。
- `PROJECTION_REVISION` 保持 `m1-01-tool-view-v5`：视图字段集合未变（stub 属 context policy，其 revision 已随 `stub_keys` 哈希变化）。
- lookback 上界用 `plan.window.seconds`：适配器不得声称读得比请求窗还远（PromQL 守卫在请求前已拒更长选择器），同时把 `lookback_start_at` 的时间运算限制在 datetime 范围内。
