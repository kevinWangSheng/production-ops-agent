## 目标

把 HolmesGPT 公开评测集里 B1 的 30 道 Elasticsearch 题变成 OpsPilot 能跑、能判分的评测：题面原文经网页人工提问交给 OpsPilot，报告按确定性规则转成文本，用上游 classifier 提示词二值判分，每题 3 遍。结果单独成轨，标「HolmesGPT 公开评测集（竞品自评集）」。全部是评测侧代码（`scripts/holmes_evals/`），`opspilot/` 一个字节不改，不翻任何 `passes`。

## 行为

- **答案隔离**：题目加载器只返回白名单字段（题面、tags、toolsets、before/after_test、setup_timeout、port_forwards、include_tool_calls、memories_generated、skip、enable_todo、evaluation、cluster_name）；`expected_output` 只有判分函数能读，judge 的理由文本只写 git 忽略的 `tmp/`，不打印、不入库。实现与测试一律用合成题目录，不读真实题的 `expected_output`。
- **钉版本**：启动时核对上游 checkout 的 HEAD 是 `a0009195468ebc55a7dff7d602b61feabe3cda1b`、`tests/llm/utils/classifiers.py` 的 sha256 与钉值一致，不符就拒绝。
- **报告转文本**：用 `opspilot.evaluation.binary_judge.project_opspilot_report`；题目 `include_tool_calls: true` 时照上游 `property_manager.py:212-231` 的格式逐字追加工具调用附件（每次调用的工具名、规范 JSON 参数、已脱敏存储视图的完整输出，含被拒调用，不截断）。没有可用报告时不送 judge、记 0、原因 `REPORT_REJECTED_BY_PRODUCT`。
- **反平移**（H-9）：评测给固定时间题的数据加了平移量时，送 judge 的文本里落在「平移后数据范围 ± 1 小时」内的 ISO 8601 时间与 `YYYY-MM-DD` 日期减去平移量还原；范围外的时间不动；只写时刻不写日期的说法不改（已知限制，披露）。返回改写个数。
- **判分**（H-16）：单一 judge Z.ai `glm-5.3-flashx`，复用 `binary_judge` 的 `ProviderConfig`/`HTTPCompletionClient`/`parse_completion`；提示词用上游 strict 与 loose 两段原文（按题的 `evaluation.correctness.type`，缺省 strict），`{{expected}}` 用 `"\n- ".join(期望条目)` 填，后接 `binary_judge.ANSWER_INSTRUCTION`；新常量 `HOLMES_EVAL_PROMPT_SHA256` 钉两段模板加作答说明。失败重试最多 2 次；请求超过 4 MiB 记 `JUDGE_REQUEST_OVERSIZE` 不重试。R8-13 的 5 题（275–278、280）不判建议条数、不附「# Suggested Skills」段、不跑 `rerun_with_memory`。
- **计分**（H-17、H-18）：主分 = 通过次数 /（题数 × 3）；每题 3 遍中过 1 或 2 遍为摇摆，补跑 3 遍单列、不进主分；无报告、judge 用尽、环境坏的 trial 记 0 留分母并单列；另报多集群 10 题一组、受时间框限制组、去掉「题或 harness 坏了」后的分数。

- `fake_es.py`（H-25，数据驱动的假 Elasticsearch）
  - `FakeElasticsearch(engineer_key: str)`：内存状态；`handle(method: str, path: str, query: Mapping[str, list[str]], headers: Mapping[str, str], body: bytes) -> tuple[int, Any]` 返回状态码与 JSON（`_bulk`/`_cat` 照 ES 形状）。认证只认 `Authorization: ApiKey <值>`：工程师 key 全权；`POST /_security/api_key` 发出的 key（`encoded` 与 `id`/`api_key`）只读，写操作 403 `security_exception`；缺失或未知 key 401。
  - 支持：`PUT /{index}`（settings、mappings，`?wait_for_active_shards`）、`DELETE /{index 或通配}`、`PUT|DELETE /_index_template/{name}`（`index_patterns` + `template.mappings`，建索引时套用）、`POST /{index}/_doc`、`POST /_bulk` 与 `POST /{index}/_bulk`（`index`/`create`/`delete` 动作，可带 `_index`、`_id`；`?refresh=`）、`POST /_refresh`、`POST /{index}/_refresh`、`POST /{index}/_forcemerge`、`GET|POST /{index}/_count`（可带 query）、`GET /{index}/_mapping`、`GET /_cat/indices[/{pattern}]`（`format=json`、`h`、`s`、`bytes`、`pri`、`health`、`expand_wildcards`）、`GET|PUT /_cluster/settings`（`include_defaults`、`flat_settings`）、`GET|POST /{index}/_search`。动态映射：日期字符串（strict_date_optional_time）→ `date`，其余字符串 → `text` 加 `.keyword`，整数 → `long`，小数 → `float`，布尔 → `boolean`，对象 → `properties`。
  - 查询：`match_all`、`bool`（must/filter/should/must_not、`minimum_should_match`）、`term`、`terms`、`match`、`match_phrase`、`range`（gt/gte/lt/lte、日期字段按时间比较）、`exists`、`prefix`、`wildcard`、`query_string`（仅 `field:value` 与 AND/OR）；`size`、`from`、`sort`（字段 asc/desc、`_doc`）、`_source`（列表或 includes/excludes）、`track_total_hits`、`timeout`、`profile`（返回固定形状的 profile 块，query type 取最外层查询类名）；聚合 `min`/`max`/`avg`/`sum`/`value_count`/`cardinality`/`terms`（size、嵌套子聚合）/`date_histogram`（`fixed_interval`）。其余构造返回 400 `parsing_exception`，未知路径 400 `illegal_argument_exception`。
  - `serve(store, host, port) -> ThreadingHTTPServer`（只许 `127.0.0.1`）；命令行 `python -m scripts.holmes_evals.fake_es --port N --key-file F` 首行打印 `{"url": ...}`。

- `LokiEntry`（冻结）：`labels: Mapping[str, str]`、`ns: int`、`line: str`；`LokiAdmin(url, *, opener=None)`：工程师直连题自带 Loki（不经网关、无凭据）：`label_names(start, end)`、`entries(start, end) -> list[LokiEntry]`（对每个标签名 `{L=~".+"}` 取全部流，`direction=forward` 每页 5000 条翻页、去重；同一纳秒超过一页抛 `SHIFT_PAGE_STUCK`，超过 200 000 条抛 `SHIFT_TOO_MANY_ENTRIES`，均确定性）、`push(entries)`（每请求至多 5000 条或 4 MiB；传输失败抛 `SHIFT_IO_FAILED`）。
- `shift_line(line, seconds) -> tuple[str, int]`：日志行里 `_STAMP` 能识别的 ISO 时间同量前移（101 的行内 `timestamp` 正是 promtail 取条目时间的字段）。
- `apply_loki_shift(admin, qid, question, now, *, setup_started) -> tuple[str, ShiftRecord]`：读 `[setup_started − 730 天, setup_started − 24h)` 的条目作为固定时间数据（之后写入的实时日志——100a 的实时线程、101 的启动日志——不动）；同量平移条目时间与行内时间；平移后晚于 `now − LEAD` 的丢掉；按原标签推回同一 Loki；原始 2025 条目留在 Loki（Loki 不能原地改写；在 24 小时框外，产品查不到）。一条固定时间条目都没有抛 `SHIFT_NO_FIXED_ENTRIES`（基础设施类，本遍重试）。
- `ShiftRecord` 新增字段（默认值使 B1 的 `as_json()` 逐字节不变，只有 `backend != "elasticsearch"` 才输出）：`backend`、`anchor_source`（`"question"`）、`fixed_entries`、`pushed`、`dropped_future`、`line_stamps_rewritten`、`streams: list[{"labels", "entries", "pushed"}]`。`original_min/max` 取推回的条目，`shifted_min/max` = 推回范围 ∪ 题面改写时刻；投递时 `DATA_AFTER_DELIVERY` 检查照旧。
