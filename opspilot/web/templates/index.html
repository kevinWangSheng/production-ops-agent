Ask OpsPilot to investigate

Incidents usually arrive from alerts on their own; use this to ask when no alert fired. It opens an incident and a Run; the Agent investigates with read-only queries and you land on the incident page.

Other controls

  • Suspension
    Pauses Agent investigation and Observer sampling, everywhere or per target. Release resumes nothing: each paused incident needs an Operator resume.
  • Version changes
    Releases the Observer watched on its own. Advisory only; nothing is approved or blocked.

What each status means

Taken over: a human owns the incident. Registering a remediation starts a Recovery watch.
{{ ui.pill("Ask or take over", todo=true) }}
The Agent stopped and handed the Run to a human. Ask or add a correction to let it continue.
{{ ui.pill("Close or reopen", todo=true) }}
The Recovery watch confirmed recovery and nobody closed the incident yet. A marker shows when the alert fired again afterwards.
{{ ui.pill("New Run or close", todo=true) }}

{{ ui.pill("Close or register", todo=true) }}

Agent conclusion levels

Supported
Strongest of the Agent's three levels; it must include at least one fact that cites evidence.
Partial
Useful findings, but the cause is unresolved.
Inconclusive
Weakest level; always used when the investigation is incomplete.
No conclusion
Nothing was published.

The level is the Agent's own rating. At every level, each fact must cite evidence from this Run; code checks the citations, not the rating. The four stored values are the records as written: Run is the current Run's state, Control is set only when paused or cancelled.
